# Advanced Scouting Dashboard

This dashboard was built to support baseball advanced scouting by organizing pitcher and hitter tendencies, matchup information, attack plans, and player-specific notes.

## Purpose

The goal of this project is to create a baseball operations style tool that helps prepare for opposing players by identifying strengths, weaknesses, tendencies, and matchup-based strategies.

## Features

- Pitcher and hitter player profiles
- Attack plan summaries
- Pitcher arsenal information
- Hitter tendency notes
- Matchup planning information
- Count-based approach notes
- Avoid zones and attack zones
- Player-specific scouting notes

## Tools Used

- HTML
- CSS
- JavaScript
- Public baseball data
- Player evaluation notes
- Baseball Savant
- FanGraphs
- Statcast

## How to Run

Open the `index.html` file in a browser.

## Data Note

This project uses public or personally created evaluation data only. No private, proprietary, or employer-owned data is included.
