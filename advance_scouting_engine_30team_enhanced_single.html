Pitcher reports

Opposing Starting Pitcher Attack Plans

Live mode uses MLB season lines and bats/throws fields. The auto-update pipeline adds Statcast arsenal usage, velocity, movement, whiff, CSW, chase, FanGraphs context, and unique player-specific notes.

How to Read the Starter Attack Plan

Threat estimates run-prevention quality from public season line, K rate, WHIP, and run prevention. Predictability estimates how pattern-based the pitcher is, using starts/workload in live mode and pitch-concentration/count tendencies after the updater runs. The final attack plan separates what our hitters should do early, when ahead, and with two strikes.

Lineup plan

Hitter Attack Cards

Cards translate public batting lines, B/T, swing profile, run value indicators, and contact-quality notes into pitcher-facing attack plans. Each player receives a unique note instead of copied template language.

Attackability Explained

Attackability is not the same as threat. A dangerous hitter can still be attackable if there is a clear path to get him out. Higher scores mean the report found a more obvious plan, usually from strikeout rate, lower walk pressure, chase/contact indicators, or a narrower damage profile. Lower scores mean the hitter is harder to game-plan because he controls the zone, makes contact, or damages multiple lanes.

75+ clear exploit lane 55–74 manageable with execution <55 careful plan, fewer free outs

Auto-Update Pipeline

This is what makes the project season-proof. The browser can refresh MLB data and head-to-head matchup context; the Python pipeline generates advanced Statcast/FanGraphs packets for all 30 teams.

Public Data Used

    How to Auto-Update

    Run the updater locally or host the folder on GitHub Pages with the included scheduled workflow. The updater writes data/teamPackets.json, which the dashboard automatically loads on refresh.

    python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python tools/update_data.py --season 2026 --lookback-days 35

    GitHub Pages workflow: the included .github/workflows/update-data.yml runs daily, rebuilds the packets, and commits the updated JSON.

    Professional caveat: this does not use proprietary Hawk-Eye, ABS, or club data. Statcast/FanGraphs outputs are public-data approximations for portfolio use.
